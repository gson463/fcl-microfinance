1) DATABASE (ikiwa bado haijakamilika)
   - Fungua: supabase/ALL_MIGRATIONS_ONE_FILE.sql
   - Supabase Dashboard → SQL Editor → bandika yote → Run
   - (Au endesha migrations 1, 2, 3 tofauti kama tayari umeisha schema.)

2) EDGE FUNCTIONS (hazipaki kwenye SQL)
   - Lazima deploy kwa CLI kutoka kwa kompyuta inayounganishwa na akaunti inayomiliki project:
       supabase login
       supabase link --project-ref <REF kutoka URL ya .env> -p '<database password>'
       npm run supabase:functions
   - Ikiwa "access denied" kwa link: tumia barua pepe ya mmiliki wa project kwenye supabase login.

3) AUTH URL
   - Authentication → URL Configuration → Site URL + Redirect URLs za app yako.

4) ADMIN WA KWANZA
   - Admin signup au create-admin-user baada ya (2).
